# R7.4.2 — Extraction des obligations (pilote)

- `legal.obligations.extract.deterministic(text)` : détection conservatrice de formulations explicites; les éléments non inférés restent `null`. Ce sont des **candidats**, non des conclusions.
- `legal.obligations.extract.llm_extract(text, chat_fn)` : LLM injectable (par exemple `legal.llm.providers.chat`), température 0, JSON strict, citation et offsets validés contre la source. Rejette les textes >12 000 caractères : segmenter en amont.
- `legal.obligations.storage.extract_and_store(conn, jurisdiction='EU'|'FR', source_id=..., source_text=..., mode='deterministic'|'llm'|'hybrid', chat_fn=...)` : transaction atomique, vérification du texte PostgreSQL, insertion du run et des obligations, provenance et checksum, statut SUCCEEDED. Erreur = rollback sans données partielles.
- `mode='llm'` nécessite `chat_fn`; `mode='hybrid'` juxtapose les candidats et supprime seulement les doublons stricts. Aucun rapprochement sémantique automatique.

## Exemple pilote

```python
import os, psycopg
from legal.obligations.storage import extract_and_store
from legal.llm.providers import chat
with psycopg.connect(os.environ['LEGAL_DSN']) as conn:
    provision_id = 'IDENTIFIANT_EXISTANT'
    text = conn.execute('SELECT text FROM eu_provision WHERE provision_id=%s', (provision_id,)).fetchone()[0]
    result = extract_and_store(conn, jurisdiction='EU', source_id=provision_id,
                               source_text=text, mode='llm', chat_fn=chat,
                               provider=os.getenv('LEGAL_LLM_PROVIDER'),
                               model=os.getenv('LEGAL_LLM_MODEL'))
    print(result)
```

Prérequis : migration `002_legal_obligations.sql` appliquée. L'API est destinée à un pilote contrôlé, pas encore à un batch de millions d'articles. Les appels LLM s'effectuent pendant la transaction : à optimiser avant le traitement massif. Les réponses brutes sont stockées dans `raw_output` pour audit ; prévoir une politique de rétention et de confidentialité. Les runs échoués sont annulés intégralement, pas inscrits comme FAILED.
