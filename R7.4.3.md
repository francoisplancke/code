# R7.4.3 — Appariement candidat EU ↔ FR

**Portée :** candidats d'appariement, pas détection définitive de surtransposition.

La dernière extraction réussie de chaque source est sélectionnée. Les obligations `REJECTED` sont exclues. Chaque preuve est contrôlée à la demande via `ensure_evidence_checked`; seuls les statuts `VERIFIED` sont éligibles. Le score est un Jaccard lexical pondéré (action 50 %, objet 35 %, acteur 15 %, normalisé sur les champs présents), pénalisé en cas de modalités différentes. Conditions et exceptions sont conservées en JSON, non assimilées à une équivalence juridique.

**Important :** l'archive fournie ne comporte aucune table relationnelle prouvant le chaînage NIM → identifiant LEGI `version.id`. Il est donc interdit de déduire automatiquement les versions françaises à partir d'un CELEX. La commande exige une liste explicite d'identifiants LEGI dont la relation à l'acte EU a été vérifiée. `scope_origin=NIM_RESOLVED` n'est à utiliser que si cette correspondance a effectivement été établie et documentée. Aucune recherche globale EU × FR n'est lancée.

## Installer

```bash
psql "$DATABASE_DSN" -v ON_ERROR_STOP=1 --single-transaction -f migrations/004_obligation_pairing.sql
python3 -m pytest -q tests/unit/test_obligation_pairing.py
```

## Exemple

```bash
PYTHONPATH=. python3 scripts/pair_obligations.py \
 --celex 32024L0001 \
 --fr-version-id UUID_LEGI_VERIFIE \
 --scope-reference 'verification-manuelle:ticket-123'
```

La transaction est validée par la connexion `psycopg`. En cas d'erreur elle est annulée. La table `legal_obligation_pair` garde des candidats `REVIEW_REQUIRED`; les appels répétés pour le même périmètre et la même version d'algorithme mettent à jour les lignes existantes. Les anciens candidats ne sont pas supprimés automatiquement : filtrer par version et provenance lors de la lecture.

## Limites

- Aucun LLM et aucun appel réseau externe.
- Score lexical = signal de classement, pas jugement d'équivalence ni de surtransposition.
- Les obligations FR doivent déjà être extraites pour les versions indiquées.
- La preuve vérifiée atteste de la fidélité textuelle, non de l'interprétation juridique.
- Aucun test d'intégration PostgreSQL n'a été exécuté ici.
